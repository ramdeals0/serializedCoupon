Why serialize a coupon?

A shared promo code can be copied, posted, and reused past the intended audience. A serialized code is issued once, tied to a promotion window and usage limit, and checked at the register or checkout before it is marked used.

  • Generic code FALL26 Anyone with the string can try it
  • Serialized code FF1234ZX98QW76 One code, one tracked redemption path

How the application works

  1. 1

    Create the coupon

    Set title, dates, usage limit, program code, and the RMS POS / ATG identifiers.

  2. 2

    Generate a batch

    The service issues unique 14-character codes and stores them against that coupon.

  3. 3

    Export for fulfillment

    Download a CSV with only the serialized code and expiration date.

  4. 4

    Validate or redeem

    POS and e-comm call the external APIs to check a code or mark it used.

What you can do here

Offer catalog

Managers create and review coupons linked to live RMS definitions before any codes exist.

Batch generation

Request a quantity, retry collisions safely, and keep generation all-or-nothing per batch.

Status lookup

Customer service searches a code to see active, pending, redeemed, or deactivated status.

Store and web APIs

Validate is check-only. Redeem validates and increments usage when the channel is allowed.
