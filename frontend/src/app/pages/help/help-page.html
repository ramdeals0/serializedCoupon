SkillNet · Serialized Coupons

Help

This console issues unique 14-character coupon codes, tracks how many times each code is used, and lets POS or e-commerce check or mark a code used.

Using the menu

Dashboard

Administrators see batch and coupon counts, recent batches, and coupon programs.

Create

Define the offer first: title, dates, usage limit, coupon program code, and POS / ATG codes.

Batch

Review generated batches, export CSV, and open a batch to see its serialized codes.

Search

Look up a serialized code. The results show status, expiration, and times used versus the usage limit.

POS Demo

Public page to call validate (check only) and redeem (validate and mark used) with an API key.

Create a coupon, then a batch

  1. 1

    Create

    Coupon program code is exactly four digits. Choose POS, Ecomm, or Both so the right identifier is required.

  2. 2

    Generate batch

    The backend creates unique codes for that coupon. Generation is all-or-nothing for the requested quantity.

  3. 3

    Export

    Download CSV with the serialized code and expiration for fulfillment.

  4. 4

    Validate or redeem

    Stores and e-comm use the external APIs. Validate does not change usage. Redeem increments times used.

Who can do what

Admin

Dashboard, create, batches, search, and deactivate a serialized code.

Manager

Create coupons, generate batches, export, and search. No dashboard and no deactivate.

Customer service

Search a code and confirm whether it is still valid for the shopper.
